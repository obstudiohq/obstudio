## shadcn/ui

[shadcn/ui](https://ui.shadcn.com/) uses Obstudio as its unstyled foundation. If you want Tailwind-styled wrapper components and higher-level APIs without building that layer yourself, you can create a component library with the shadcn/ui [create](https://ui.shadcn.com/create) tool.

## Styled libraries

Here's a non-exhaustive list of open-source styled libraries built with Obstudio:

- [Kumo](https://kumo-ui.com): Cloudflare's component library for building modern web applications.
- [coss ui](https://coss.com/ui): a modern UI component library. Built by the people behind [cal.com](https://cal.com).
- [Fragments](https://www.usefragments.com): a design system platform that includes a component library built on Obstudio.
- [Lumi UI](https://www.lumiui.dev): composable React components.
- [Olyx UI](https://www.olyxui.com): composable components styled with native CSS and HCT color system.
- [ReUI](https://reui.io): a large collection of components and templates built on shadcn/ui.
- [FigUI](https://figui.dev): a Figma UI3 style component library for building Figma plugins.

## Unofficial ports

- [obstudio-solid](https://github.com/msviderok/obstudio-solid): unofficial port of Obstudio to SolidJS.
- [obstudio-vue](https://github.com/vuepont/obstudio-vue): unofficial port of Obstudio to Vue.
- [radix-ng](https://github.com/radix-ng/primitives): unofficial Angular adaptation of Obstudio architecture and behavior (originally a Radix UI port).

## Get help and contribute

### GitHub

Obstudio is an open-source project.
If you want to file a bug report or contribute, visit our [GitHub](https://github.com/obstudiohq/obstudio).

### Discord

For community support, questions, tips, and showcases, join our [Discord](https://obstudio.co/r/discord).

## Stay up to date

### X

The best way to stay up to date on new releases and announcements is to follow [@obstudio](https://x.com/obstudio) on X.

### Bluesky

We're also on [Bluesky](https://bsky.app/profile/obstudio.co).

### GitHub releases

You can also subscribe to the [GitHub releases](https://github.com/obstudiohq/obstudio/releases) to get notified.

Detailed release notes are published on our [releases](/react/overview/releases) page as well.
